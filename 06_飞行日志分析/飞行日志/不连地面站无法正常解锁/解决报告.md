对应当前参数文件里这一项：
NAV_DLL_ACT = 1
COM_DLL_EXCEPT = 0
COM_DL_LOSS_T = 10
NAV_DLL_ACT 是 Data Link Loss / 地面站链路丢失保护动作。PX4 官方文档说明，GCS/MAVLink 数据链路丢失保护由 COM_DL_LOSS_T、NAV_DLL_ACT、COM_DLL_EXCEPT 控制；其中 NAV_DLL_ACT 可设为 Disabled/Hold/Return/Land 等动作。你现在 NAV_DLL_ACT=1，等于要求存在地面站链路，否则健康检查失败，所以离开 QGC/数传就不让解锁。参考：PX4 Data Link Loss Failsafe。
现在的结论很确定：
根因 = NAV_DLL_ACT 开启了地面站链路丢失保护
现象 = 不连接 QGC/数传时，PX4 认为没有 ground control station，预飞检查失败，拒绝解锁
不是 = 避障没开、急停开关、Offboard 开关
你的当前阶段“没装机载电脑、没装避障、想脱离地面站用遥控器本地解锁”，建议直接改：
NAV_DLL_ACT = 0

下拉菜单含义：
Disabled     关闭地面站丢失保护
Hold mode    丢失地面站后悬停/保持
Return mode  丢失地面站后返航
Land mode    丢失地面站后降落
Terminate    终止飞行，危险，不要选
Disarm       上锁，飞行中可能直接停机，不要选
你现在这种情况应该选：
Disabled

后期自动飞行真正更重要的是这些保护：
COM_OBL_RC_ACT    Offboard 丢失后的动作
COM_OF_LOSS_T     Offboard 丢失判定时间
COM_RC_LOSS_T     遥控器丢失判定时间
NAV_RCL_ACT       遥控器丢失后的动作
COM_LOW_BAT_ACT   低电量动作
COM_POS_LOW_ACT   位置估计变差后的动作
