## 使用规则

1. 每次飞行后，日志统一按 `<日期>_<问题简述>/` 格式新建目录存放
2. 分析完成后在同一目录下补充 `分析报告.md`
3. 新问题追加到上方索引表
4. 解决后更新状态为 ✅
