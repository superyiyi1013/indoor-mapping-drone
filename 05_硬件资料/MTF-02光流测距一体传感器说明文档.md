# MTF-02/02P 光流测距一体传感器 使用说明文档
[官方说明书](https://micoair.cn/docs/MTF02-02P-guang-liu-ce-ju-yi-ti-chuan-gan-qi-yong-hu-shou-ce)
## 一、产品概述

MTF-02/02P 是微空科技（MicoAir）研发的光流测距一体传感器，专为室内无GPS环境下的无人机自主飞行设计。该模块将**光流传感器**和**激光测距传感器**集成在超小体积内，可同时提供水平位置（X、Y）和精确高度（Z）数据，实现室内定点悬停、定点起降和轨迹飞行。

### 核心特点

- **一体化设计**：光流传感器 + 激光测距传感器 + 数据融合芯片，三合一
- **超轻超小**：仅重 1-1.5g，尺寸 21.6×16×6.5mm（02P）/ 25×10×4.5mm（02）
- **即插即用**：串口输出，支持 MAVLink 协议，兼容 PX4/Ardupilot/INAV 飞控
- **室内专用**：MTF-02 针对室内环境优化，MTF-02P 支持室内外通用
- **高精度**：水平定位 ±5-10cm，高度测量 ±2cm

## 二、传感器内部结构

MTF-02 不是单一传感器，而是**两个独立传感器 + 一个融合芯片**的集成模块：

```
┌─────────────────────────────────────┐
│         MTF-02 模块内部结构          │
├─────────────────────────────────────┤
│                                     │
│  ┌─────────────┐  ┌─────────────┐  │
│  │  光流传感器  │  │ 激光测距传感器│  │
│  │  (摄像头)   │  │   (TOF)     │  │
│  │             │  │             │  │
│  │ • 向下拍摄   │  │ • 向下发射   │  │
│  │ • 42°视场角  │  │   激光脉冲   │  │
│  │ • 测水平位移 │  │ • 2°/20°视场角│  │
│  │ • 输出 ΔX,ΔY│  │ • 测垂直距离 │  │
│  │             │  │ • 输出 Z高度 │  │
│  └──────┬──────┘  └──────┬──────┘  │
│         │                │         │
│         └────────┬───────┘         │
│                  ▼                 │
│         ┌─────────────┐            │
│         │  数据融合芯片 │            │
│         │             │            │
│         │ • 接收光流数据│            │
│         │ • 接收测距数据│            │
│         │ • 融合计算   │            │
│         │ • 输出X,Y,Z │            │
│         └──────┬──────┘            │
│                │                   │
│                ▼                   │
│         ┌─────────────┐            │
│         │  串口输出    │            │
│         │ 115200bps   │            │
│         │ MAVLink协议 │            │
│         └─────────────┘            │
│                                     │
└─────────────────────────────────────┘
```

### 为什么需要两个传感器配合

光流传感器要算出准确的水平位移，**必须知道当前高度**：

```
场景：飞机往前飞了1米

高度1米时：
    摄像头看到地面移动了 100 像素
    → 算法：100像素 ÷ 1米高度 = 移动了1米 ✓

高度5米时：
    摄像头看到地面只移动了 20 像素
    → 不告诉算法高度：20像素 ÷ 1米 = 以为只移动了0.2米 ✗
    → 告诉算法高度5米：20像素 ÷ 5米 = 正确算出1米 ✓
```

**结论**：光流传感器输出原始像素位移，激光测距告诉它当前高度，两者结合才能算出准确的水平位移。

## 四、接口定义与连接

### 引脚定义

| 引脚 | 名称 | 说明 |
|------|------|------|
| 1 | GND | 电源地 |
| 2 | 5V | 电源正（5V输入）|
| 3 | Rx | 串口接收，接飞控 Tx |
| 4 | Tx | 串口发送，接飞控 Rx |

### 与 Pixhawk 2.4.8 连接

```
MTF-02 模块              Pixhawk 2.4.8 飞控
┌─────────┐             ┌─────────────┐
│ 5V      │◄───────────►│ 5V          │
│ GND     │◄───────────►│ GND         │
│ Rx      │◄───────────►│ TELEM1/2 Tx │
│ Tx      │◄───────────►│ TELEM1/2 Rx │
└─────────┘             └─────────────┘
```

**连接说明**：
- 使用 TELEM1 或 TELEM2 串口
- 只需 4 根杜邦线
- 模块由飞控 5V 供电

### 安装方向

- 模块应**水平安装**，镜头垂直向下
- 模块上的箭头或标识应指向飞机前方
- 安装位置尽量靠近飞控中心，减少振动
- 避免螺旋桨气流直接吹到模块窗口

## 六、PX4 飞控配置指南

### 6.1 硬件连接

1. 将 MTF-02 的 4 根线连接到 Pixhawk 的 **TELEM1** 或 **TELEM2** 接口
2. 确保模块水平安装，镜头朝下
3. 上电检查模块指示灯状态

### 6.2 PX4 v1.14.x 配置步骤

#### 第一步：配置串口

| 参数 | 设置值 | 说明 |
|------|--------|------|
| `MAV_1_CONFIG` | `TELEM1` 或 `TELEM2` | 选择连接端口 |

**设置后重启飞控**

#### 第二步：配置串口参数

| 参数 | 设置值 | 说明 |
|------|--------|------|
| `MAV_1_MODE` | `Normal` | 普通模式 |
| `SER_TEL1_BAUD` | `115200 8N1` | 波特率匹配 |

#### 第三步：启用光流和测距

| 参数 | 设置值 | 说明 |
|------|--------|------|
| `EKF2_OF_CTRL` | `Enabled` | **启用光流辅助定位** |
| `EKF2_RNG_CTRL` | `Enabled` | **启用激光测距辅助** |
| `EKF2_HGT_REF` | `Range sensor` | **使用测距仪作为高度源** |

**设置后重启飞控**

#### 第四步：验证配置

1. 用 USB 连接飞控到电脑
2. 打开 QGroundControl
3. 进入 **MAVLink Inspector** 页面
4. 确认能看到以下消息：
   - ✅ `DISTANCE_SENSOR`（激光测距数据）
   - ✅ `OPTICAL_FLOW_RAD`（光流数据）

> **注意**：如果通过数传连接，由于带宽限制，可能看不到 `OPTICAL_FLOW_RAD` 消息。这是正常的，不代表传感器没工作。使用 USB 连接才能看到完整消息。

### 6.3 PX4 v1.12.x - 1.13.x 配置

| 参数 | 设置值 |
|------|--------|
| `MAV_1_CONFIG` | `TELEM n` |
| `MAV_1_MODE` | `Normal` |
| `SER_TELn_BAUD` | `115200 8N1` |
| `SENS_FLOW_ROT` | `No rotation` |
| `EKF2_AID_MASK` | `use optical flow` |
| `EKF2_RNG_AID` | `Range aid enable` |
| `EKF2_HGT_MODE` | `Range sensor` |

## 七、关键参数说明

### EKF2 相关参数

| 参数 | 功能 | 本项目设置 |
|------|------|-----------|
| `EKF2_OF_CTRL` | 光流控制开关 | `Enabled`（启用光流）|
| `EKF2_RNG_CTRL` | 激光测距控制开关 | `Enabled`（启用测距）|
| `EKF2_HGT_REF` | 高度参考源 | `Range sensor`（使用测距仪）|

### 参数作用解释

```
EKF2_OF_CTRL = Enabled
    ↓
飞控融合光流传感器数据
    ↓
获得水平速度 Vx, Vy 和水平位置 X, Y

EKF2_RNG_CTRL = Enabled  
    ↓
飞控融合激光测距数据
    ↓
获得精确高度 Z

EKF2_HGT_REF = Range sensor
    ↓
高度控制使用激光测距（而不是气压计）
    ↓
高度精度从 ±30cm 提升到 ±2cm
```

## 八、实现功能

### 8.1 定点悬停

```
水平方向：
    光流传感器持续监测 X, Y 位移
    → 飞控控制飞机回到原点
    → 悬停精度：±5-10cm

垂直方向：
    激光测距持续监测 Z 高度
    → 飞控精确保持设定高度
    → 定高精度：±2cm
```

### 8.2 定点起降

```
起飞：
    1. 解锁，起飞到设定高度（如1.5米）
    2. 光流记录当前 (X, Y) 为原点 (0, 0)
    3. 激光测距精确保持高度

降落：
    1. 收到降落指令
    2. 飞控控制飞机回到 (X=0, Y=0)
    3. 缓慢下降，激光测距精确控制高度
    4. 触地检测 → 锁定电机
```

### 8.3 轨迹飞行

```
预设航点：
    A(0, 0, 1.5) ──► B(2, 0, 1.5) ──► C(2, 2, 1.5)

执行过程：
    1. 从 A 点起飞
    2. 光流导航飞往 B 点（水平位移 2米）
    3. 光流导航飞往 C 点（水平位移 2米）
    4. 激光测距全程精确保持 1.5米高度
```

## 九、使用限制与注意事项

### 9.1 工作环境要求

| 条件 | 要求 | 说明 |
|------|------|------|
| **地面纹理** | 必须有可见纹理 | 花纹地板、地毯可以；纯白墙、纯黑地面不行 |
| **环境光照** | >60Lux | 正常室内照明足够，黑暗环境不行 |
| **飞行高度** | <2.5m（02版）| 超过量程后测距失效 |
| **飞行速度** | <7m/s（@1m高度）| 速度越快精度越低 |
| **最小工作距离** | >8cm | 离地面太近光流失效 |

### 9.2 地面纹理要求

✅ **可以工作的地面**：
- 木地板（有木纹）
- 瓷砖地板（有缝隙和花纹）
- 地毯（有纹理）
- 水泥地（有细小颗粒纹理）

❌ **不能工作的地面**：
- 纯白色墙面/地面
- 纯黑色地面
- 光滑镜面地面
- 强反光地面

### 9.3 常见问题

| 问题 | 可能原因 | 解决方法 |
|------|---------|---------|
| 看不到光流数据 | 协议不匹配 | 确认模块协议为 Mavlink_px4 |
| 看不到光流数据 | 使用数传连接 | 改用 USB 连接查看 |
| 定位漂移严重 | 地面无纹理 | 更换飞行场地 |
| 高度跳动大 | 地面反光/透明 | 避免玻璃/镜面地面 |
| 悬停不稳 | 模块振动大 | 加装减震垫 |
| 高度突然跳变 | 超出测距范围 | 降低飞行高度 |
