# D435i + PX4 室内自动飞行开发指南

> **文档定位**：本指南为激光雷达（FAST-LIO + EGO-Planner）阶段完成后的**第二阶段**开发文档。RealSense D435i 在本阶段不承担主定位任务，而是作为**近距离避障**与**视觉冗余备份**接入系统，最终提升室内自动飞行的安全性。

---

## 一、总体架构

### 1.1 系统架构定位

本阶段在已有激光雷达系统基础上，叠加 D435i 视觉模块，形成多传感器融合的室内自动飞行平台：

- **主定位**：Livox MID360 + FAST-LIO
- **主规划**：EGO-Planner
- **近距离避障**：RealSense D435i（核心任务）
- **备份定位**：D435i VIO（可选）
- **安全备份**：光流定点（已验证）

### 1.2 D435i 功能分工

| 功能 | 优先级 | 说明 |
|------|--------|------|
| **Collision Prevention（碰撞预防）** | **P0 必须做** | 利用 D435i 深度图生成障碍物距离信息，使 PX4 在 Position / Offboard 模式下自动减速或刹停 |
| **VIO 冗余定位** | P1 建议做 | 当激光雷达在狭窄走廊、玻璃墙等场景失效时，提供备用位姿源 |
| **视觉点云补盲** | P2 可选 | 将 D435i 深度图转换为点云，补充激光雷达在近距盲区的障碍物信息 |

> **核心原则**：先让避障功能跑稳，再逐步叠加 VIO 和规划器集成，避免同时开启过多新功能导致调试困难。

│   │   ├── mavros/               # 若采用 apt 安装则无需源码
│   │   ├── fast_lio/             # 激光雷达阶段已存在
│   │   ├── ego_planner/          # 规划器阶段已存在
│   │   └── d435i_tools/          # 自研 D435i 工具包
│   │       ├── scripts/          # 避障节点、VIO 桥接节点、启动脚本
│   │       └── launch/           # 相关 launch 文件
│   └── devel/ / build/
├── librealsense/                 # librealsense2 SDK 源码
├── calibration/                  # 标定文件存档
│   ├── d435i/                    # D435i 配置文件、Kalibr 标定结果

    ├── install_realsense.sh      # D435i 驱动安装脚本

## 三、分步实施流程

### Step 0：环境确认

**前置条件**（应在激光雷达阶段已完成）：
- Jetson Orin NX 已刷 JetPack 5.x（Ubuntu 20.04）
- ROS Noetic 已安装并配置
- MAVROS 已安装，且与 PX4 真机的连接已验证
- 光流定点功能已验证通过

**新增检查**：
- 确认 Jetson USB 3.0 口可正常识别 D435i

---

### Step 1：D435i 驱动安装

Jetson 平台需源码编译 `librealsense2` 并开启 CUDA 加速，随后编译 `realsense-ros`。

**关键检查点**：
- 启动深度流后，确认深度图 topic 以预期频率稳定输出
- 建议初始分辨率使用较低配置以降低 CPU 占用

---

### Step 2：PX4 Collision Prevention 避障（核心任务）

将 D435i 深度图处理为障碍物距离数组，通过 MAVROS 发送给 PX4，使飞控在 Position 模式下实现自动刹停。

**实施要点**：
- 编写深度图 → `ObstacleDistance` 的转换节点
- 对深度图进行 ROI 裁剪，过滤地面和天花板干扰
- 将扇区数组进行循环移位，使正前方对应索引 0
- 配置 PX4 碰撞预防相关参数

**地面测试**（不装桨）：
- 在 QGroundControl 的 MAVLink Inspector 中检查 `OBSTACLE_DISTANCE` 消息
- 手持飞机靠近障碍物，确认数值变化合理
- 在 Position 模式下推杆，确认飞控拒绝继续靠近障碍物

**试飞**：
- 低空 Position 模式悬停后，缓慢靠近障碍物，观察自动减速/刹停效果

---

### Step 3：D435i VIO 冗余定位（可选）

当激光雷达在特征稀疏环境（长走廊、玻璃墙）中失效时，D435i VIO 可作为备份定位源。

**推荐方案**：使用 OpenVINS
- 官方提供 D435i 配置文件，ARM 平台运行稳定，CPU 占用较低
- 输出标准 Odometry，易于桥接给 MAVROS

**实施要点**：
- 启动 D435i 红外图 + IMU 数据流（关闭红外发射器）
- 运行 OpenVINS 估计节点
- 编写 VIO 位姿 → `/mavros/vision_pose/pose` 的桥接节点
- 处理初始 Yaw 对齐问题，确保机头朝向与 PX4 EKF 坐标系一致

**切换逻辑建议**：
- 正常情况下由 FAST-LIO 提供主定位
- 当检测到 FAST-LIO 发散时，可切换发布源为 OpenVINS
- 或采用单 topic 切换策略，避免多个视觉源同时注入导致 EKF 异常

---

### Step 4：与 EGO-Planner 集成（可选）

若希望规划器利用 D435i 检测到的近距离障碍物，可将 D435i 深度图转换为点云，输入 EGO-Planner 的局部地图。

**实施要点**：
- 利用 `realsense-ros` 的点云过滤器生成 `sensor_msgs/PointCloud2`
- 将该点云 topic 接入 EGO-Planner 的地图输入端
- 建议仅将 D435i 点云用于近距离（如 0.5~3 米）补盲，主地图仍由激光雷达构建

**注意事项**：
- D435i 点云在快速运动时存在运动模糊，稳定性不如 Livox MID360
- 需合理设置点云过滤范围，避免引入过多噪声

---

### Step 5：一键启动与上电自检

为不同使用场景编写启动脚本：
- **避障专用启动脚本**：仅启动深度流 + 避障节点
- **VIO 备份启动脚本**：启动红外/IMU 流 + OpenVINS + 桥接节点

同时编写上电自检脚本，在每次飞行前自动检查：
- D435i USB 连接状态
- ROS Master 运行状态
- MAVROS 连接状态
- 深度流 / 避障数据输出状态

## 四、试飞检查清单

每次飞行前必须执行以下检查：

1. **地面测试**
   - 不装桨，上电启动避障节点
   - 手持飞机靠近障碍物，确认 QGC 中障碍物数据正确
   - Position 模式下确认电机响应合理（靠近障碍物时转速变化或拒绝前进）

2. **低空悬停**
   - 装桨后 Stabilize 模式起飞至 1 米高度
   - 切换 Position 模式，观察悬停稳定性

3. **避障验证**
   - Position 模式下缓慢推杆靠近障碍物
   - 确认飞控自动减速或刹停

4. **自动飞行验证**
   - 在 FAST-LIO + EGO-Planner 正常工作前提下发送轨迹
   - 观察 D435i 对突发障碍物的响应是否及时

**安全提醒**：
- D435i 对玻璃、镜面、光滑金属、纯黑/纯白墙面及强光直射场景可能失效
- 30 cm 以内为深度盲区，无法处理贴脸碰撞
- 遥控器必须随时可切换至 Stabilize 或 Altitude 模式

## 五、实施路线图

| 阶段 | 任务 | 预计时间 | 前置依赖 |
|------|------|---------|---------|
| **激光雷达阶段** | FAST-LIO + EGO-Planner + 真机定点/自动飞行 | 2~4 周 | 无 |
| **D435i Step 1** | 安装驱动，确认深度图正常输出 | 半天 | 激光雷达阶段完成 |
| **D435i Step 2** | **Collision Prevention 避障**（本阶段核心） | 1~2 天 | Step 1 |
| **D435i Step 3** | OpenVINS 备份定位 | 2~3 天 | Step 1 |
| **D435i Step 4** | 与 EGO-Planner 点云融合 | 1~2 天 | Step 2 |

> **关键建议**：基于已有的光流定点成功经验，**Step 2（Collision Prevention）** 是最应优先攻克的核心任务。它直接赋予无人机"不撞墙"的基础能力。VIO 和点云融合属于锦上添花，应在避障功能稳定后再逐步叠加。
