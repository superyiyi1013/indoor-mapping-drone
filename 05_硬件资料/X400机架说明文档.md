# X400 机架规格说明

## 基本信息

| 项目 | 参数 |
|------|------|
| 型号 | X400 (X4 PRO升级款) |
| 轴距 | 400mm |
| 机架类型 | 四轴（X型布局） |
| 适用桨叶 | 8寸 |
| 定位 | 航拍/FPV训练机架 |
| 材质 | 碳纤维 |

## 机架结构参数

| 项目 | 参数 |
|------|------|
| 机臂碳管规格 | 14×16×110mm (外径×内径×长度) |
| 中心板上板厚度 | 1.5mm |
| 中心板下板厚度 | 1.5mm |
| 机架内部高度 | 30mm |
| 机架重量 | 约360g |

| 电机座适配碳管 | 16mm直径 |

### 飞控安装
| 项目 | 参数 |

| 飞控安装孔距 | 30.5×30.5mm (M3螺丝) |
| 兼容飞控 | APM / PIX / DJI 系列 |


## 核心特点

- **轴距400mm**：兼顾便携性与稳定性，适合航拍及轻度负载任务
- **8寸桨叶兼容**：匹配常见动力系统，配件选择丰富
- **X型布局**：结构紧凑，飞行灵活，适合FPV及航拍应用
- **碳纤维材质**：轻便耐用，整机重量仅约360g
