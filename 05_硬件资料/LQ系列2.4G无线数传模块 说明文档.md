# LQ系列2\.4G无线数传模块 说明书
官方说明：[LQ说明书](https://docs.amovlab.com/amov-lq-wiki/#/)
适配设备：AMOVLAB LQ 无线数传 \| 搭配 PX4 飞控 \+ QGC 地面站
适用场景：飞控无线 Mavlink 数据透传、地面站远程连接

## 一、设备基础信息

1. 模块组网架构

- 天空端（机载端）：绑定飞控，STA 从机模式，默认 IP：\[192\.168\.1\.201\]\(192\.168\.1\.201\)

- 地面端（电脑端）：接电脑侧，AP 主机模式，默认 IP：\[192\.168\.1\.200\]\(192\.168\.1\.200\)

- 网段统一：192\.168\.1\.X，电脑固定网段 IP 设为 \[192\.168\.1\.123\]\(192\.168\.1\.123\)

2. 默认后台账号密码
账号：<管理员提供>  密码：<管理员提供>

3. 访问后台方式
浏览器输入对应 IP 即可进入网页配置页

## 二、硬件接线规范

### 1\. 天空端 ↔ PX4 飞控接线

使用飞控 TELEM1 串口

- 飞控 TX → 数传串口 RX

- 飞控 RX → 数传串口 TX

- 飞控 GND → 数传 GND（必须共地，缺一不可）

### 2\. 供电要求

- 天空端：机载电池供电，禁止仅串口弱供电

- 地面端：USB / 适配器常规供电

### 3\. 组网指示灯

LINK 灯常亮 = 天地端组网成功；闪烁 = 组网异常

## 三、数传模块核心配置（仅配置天空端）

地面端保持出厂 AP 默认参数即可，无需改动串口

### 天空端串口 1 透传参数（固定标配）

1. 串口基础参数
波特率：115200（模块硬件最高速率）  数据位：8  停止位：1  校验位：无

2. 透传模式设置
开启客户端：开启
开启服务器：关闭
连接类型：UDP
目的 IP：\[192\.168\.1\.123\]\(192\.168\.1\.123\)（电脑 IP）
目的端口：14540

3. 配置操作
修改完成点击**保存**，重启模块生效

4. 地面端校验
SSID、无线信道、加密密码与天空端完全一致

## 四、PX4 飞控配套参数配置

### 1\. TELEM1 串口协议

SER\_TEL1\_BAUD：115200
SER\_TEL1\_PROTOCOL：Mavlink2
MAV\_0\_CONFIG：TELEM1

### 2\. 供电适配设置（本机 12V 稳压供电）

1. 关闭电源冗余检测：COM\_POWER\_COUNT = 0

2. 关闭供电报错校验：CBRK\_SUPPLY\_CHK = 894281

3. 禁用电池电压检测：BAT1\_SOURCE = \-1

### 3\. 无定位解锁调试参数

COM\_ARM\_WO\_GPS = 1
COM\_ARM\_EKF\_POS/VEL/HGT 全部设为 0

## 五、QGC 地面站连接设置

1. 添加 UDP 连接
连接类型：UDP
IP 地址：\[192\.168\.1\.123\]\(192\.168\.1\.123\)
端口号：14540

2. 自动连接优化
勾选默认连接、自动重连，解决飞控重启后手动点连接问题

3. 连接顺序
设备全部上电→等待数传组网→打开 QGC 自动建联

## 六、常见故障排查

1. 数传组网失败
核对天地端 WiFi 名称、密码、信道一致；检查供电与天线安装

2. QGC 无法连上飞控
核对串口波特率统一 115200；关闭电脑防火墙；IP 端口一一对应

3. 电源报错 Power redundancy not met
使用 12V 供电时，套用关闭供电检测参数即可解锁

4. 解锁拒绝 无有效位置预估
开启无 GPS 解锁参数，室外飞行恢复 GPS 定位校验

5. 飞控重启断开连接
QGC 开启自动连接；数传保持客户端 UDP 透传模式

## 七、使用注意事项

1. 调试模式关闭供电、定位检测，正式户外飞行务必恢复默认安全参数

2. 串口接线严格收发交叉，地线必须共地，避免数据乱码无信号

3. 2\.4G 频段远离遥控、图传等干扰设备，降低卡顿丢包

4. 每次修改模块 / 飞控参数后，均需重启设备生效
