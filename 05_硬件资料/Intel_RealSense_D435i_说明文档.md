## 一、产品概述

D435i 是在 D435 基础上增加了 **6 轴 IMU（惯性测量单元）** 的深度相机，专为**移动机器人、无人机、SLAM 应用**设计。

**核心特点：**
- 主动红外立体视觉深度感知
- 全局快门，适合高速运动场景
- 集成 Bosch BMI055/BMI085 6DoF IMU
- 深度与 IMU 数据硬件时间同步
- 紧凑轻便（90×25×25mm，约72-75g）

## 三、坐标系定义（关键！）

D435i 使用 **右手坐标系**，与 OpenCV 兼容：

```
        Z（前，Forward）
        ↑
        |
        |
X（右，Right）←——— 相机中心
        |
        |
        ↓ Y（下，Down）
```

**重要说明：**
- **正 X 轴指向右侧**
- **正 Y 轴指向下方**（注意不是向上！）
- **正 Z 轴指向前方**（深度方向）
- IMU 数据通过**外参矩阵**自动对齐到深度传感器坐标系

> 加速度计静止时读数约为 **-9.8 m/s²**（沿 Y 轴向上抵抗重力），因为正 Y 轴向下。

## 四、深度质量指标

| 指标 | 规格 |
|------|------|
| **Z 轴精度（绝对误差）** | ≤ 2% @ 2m |
| **填充率（Fill Rate）** | ≥ 99% |
| **RMS 误差（空间噪声）** | ≤ 2% |
| **时间噪声（像素级）** | ≤ 1% |

> 测量基于 80% 深度 FOV 的 ROI（感兴趣区域）。

## 六、IMU 校准（必须做！）

D435i 的 IMU **出厂未校准**，静止时可能有非零角速度输出。

**校准步骤：**

```bash
# 安装 SDK 后运行官方校准工具
rs-imu-calibration-tool

# 按提示将相机静止放置多个姿态
# 校准数据自动写入设备 NVRAM
```

**校准后效果：**
- 静止时陀螺仪读数接近 0
- 加速度计读数接近 -9.8（Y 轴）
- 深度与 IMU 外参已预置，不可修改

## 七、与无人机/飞控集成要点

### 7.1 物理安装

| 项目 | 建议 |
|------|------|
| **安装位置** | 机腹朝下，镜头垂直地面 |
| **减震** | 使用橡胶减震球，隔离电机振动 |
| **朝向** | Z 轴向下（与飞控 NED 坐标系对齐） |
| **高度** | 距离地面 30cm 以上（Min-Z 限制） |

### 7.2 与飞控的数据流

```
┌─────────────┐      USB       ┌─────────────┐      MAVLink      ┌─────────┐
│ RealSense   │ ─────────────→ │ 机载计算机   │ ───────────────→ │ Pixhawk │
│ D435i       │   深度+IMU     │ (Jetson/PI)  │   位置/速度估计    │  6C     │
└─────────────┘                └─────────────┘                   └─────────┘
         ↓                            ↓
    librealsense SDK              VINS/ORB-SLAM3
    输出: 深度图+IMU数据           输出: 6DoF位姿
                                  通过 MAVROS/MAVSDK 发给飞控
```

### 7.3 PX4 飞控需配置的参数（后期）

| 参数 | 值 | 说明 |
|------|---|------|
| `EKF2_EV_CTRL` | 1 | 启用外部视觉（External Vision）输入 |
| `EKF2_EV_DELAY` | 根据实际延迟调整 | 视觉数据延迟补偿 |
| `EKF2_EV_NOISE_MD` | 根据精度设置 | 视觉位置噪声模型 |
| `MAV_1_CONFIG` | 102 (TELEM2) | 机载计算机接 TELEM2 |

## 八、室内使用注意事项

| 场景 | 影响 | 解决 |
|------|------|------|
| **强光直射** | 红外投射器被淹没，深度失效 | 避免阳光直射，室内灯光一般不影响 |
| **透明玻璃/水面** | 红外穿透，无反射，深度黑洞 | 额外传感器或算法处理 |
| **高反光表面** | 红外过反射，深度飞点 | 调整相机角度，避免正对 |
| **纯黑吸光表面** | 红外被吸收，无反射 | 改善环境光，或用结构光相机 |
| **快速旋转/震动** | 立体匹配失效，深度撕裂 | 减震安装，降低飞行速度 |
