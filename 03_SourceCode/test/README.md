# 测试与新机初始化总指南

这个 `README` 现在同时承担两个角色：

- 作为 `test/` 目录总入口，说明阶段测试怎么执行
- 作为新机替换后的初始化教程，指导把机载电脑重新配置到可跑阶段 03 ~ 06

如果你刚更换了新的机载电脑，先看本文的“新电脑初始化教程”；如果电脑已经配置完成，只需要按本文最后的阶段索引执行对应测试。

## 目录结构

| 目录 | 作用 |

---

## 执行规则

1. 按阶段顺序执行，不跳阶段。
2. 每个阶段文件夹内从 `01` 开始执行。
3. 每个验收文件只记录结论：`通过 / 未通过`、问题、确认人。
4. 出现复杂问题时，写入 `00_总控/05_问题记录与复测模板.md`。
5. 拆桨验收未通过，禁止上桨自动飞行。

## 新电脑初始化

完整流程（系统安装 → 拉取编译 → 串口配置 → 链路验证 → 开机自启）统一收录在项目根目录 [初始化指南.md](../初始化指南.md)，此处不再重复。

新电脑配置完成后，按以下顺序回归验收（不跳阶段）：

1. `阶段03_机载计算机MAVROS接入验收/01_机载电脑系统与串口链路检查.md`
2. `阶段03_机载计算机MAVROS接入验收/02_MAVROS拆桨Offboard接管测试.md`
3. `阶段04_D435i前向感知验收`
4. `阶段05_PX4避障链路验收/01_PX4避障链路与Collision_Prevention拆桨测试.md`
5. `阶段06_Offboard短距离避障飞行验收/README.md`
