# 05_1m起飞等待接管超时降落测试

## 目标

Offboard 起飞至 1.0 m，悬停等待飞手接管。若 20 s 内检测到模式离开 OFFBOARD，脚本停止 setpoint 交给飞手；若超时未接管，脚本自动执行降落。验证起跳段动力响应和超时自动降落兜底。

---

## 本项飞行程序

| 项目 | 内容 |
|---|---|
| 入口脚本 | `stage06/06_takeoff_1m_takeover_or_autoland.sh` |
| Python 任务 | `tasks/stage06/06_takeoff_1m_takeover_or_autoland.py` |
| 接管判断 | 模式离开 OFFBOARD |
| 超时兜底 | 20 s 后自动降落 |

---

## 前置条件

- 阶段 06-01 人工接管测试已通过。
- 机载电脑上电后自启动避障链路已常驻运行。
- `CP_GO_NO_DATA=1` 已按仅前向 D435i 配置确认。
- 安全员到位，场地空旷。

---

## 默认参数

| 脚本变量 | 默认值 | 说明 |
|---|---|---|
| `ALT` | `1.0` | 目标高度，单位 m |
| `TAKEOVER_TIMEOUT` | `20` | 等待接管最长时间，单位 s |

---

## 运行方式

```bash
cd /home/<user>/X400_workspace/03_SourceCode/mavros_auto_flight/stage06
bash 06_takeoff_1m_takeover_or_autoland.sh
```

---

## 现场步骤

1. 运行本项一键脚本。
2. 脚本提示安全确认时输入 `Y`。
3. 脚本自动 Offboard、解锁、起飞到 1.0 m 并悬停。
4. 到达后脚本打印接管倒计时。
5. 验证人工接管：拨模式开关离开 OFFBOARD，脚本提示已检测到接管并停止 setpoint，飞手手动降落。
6. 验证超时自动降落：20 s 内不接管，脚本自动执行降落。
7. 任意异常立即遥控器接管或 QGC Land。
