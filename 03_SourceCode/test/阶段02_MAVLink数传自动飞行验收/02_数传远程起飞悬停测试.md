# 02_数传远程起飞悬停降落测试

## 目标

确认地面电脑可通过数传链路执行远程起飞、短时悬停、自动降落，并可被人工接管。

## 前置条件

- MAVLink 链路检查通过。
- 基础悬停能力通过。
- 场地安全，安全员到位。

## 说明

起飞、悬停、自动降落和人工接管为同一脚本的连续流程，无需中途切换脚本或手动触发降落。

脚本 `takeoff_hover_1m_test.py` 的流程：起飞到约 1 m → 悬停 → 悬停计时结束 → 自动下降 → 发送 `NAV_LAND` → 等待落地并上锁。

## 测试步骤

| 操作 | 通过标准 |
|---|---|
| 拆桨运行脚本 | Offboard/解锁逻辑无异常 |
| 装桨低空起飞 | 起飞高度受控，到约 1 m |
| 原地悬停 | 短时悬停稳定 |
| 等待悬停计时结束，脚本自动进入下降阶段 | 下降平稳，无长时间悬停不落 |
| 观察落地后脚本上锁 | 电机停止，状态正常 |
| 人工接管（各阶段均可测试） | 可立即切回人工模式 |

## 命令

```powershell
.\.venv\Scripts\python.exe .\03_SourceCode\mavlink_auto_flight\takeoff_hover_1m_test.py
```

## 人工观察

- 降落阶段高度异常、横向漂移时立即接管。
- 落地后确认电机停止。

- 脚本可正常退出。
- 遥控器可立即接管。
