# 01_D435i设备枚举USB3与深度图输出测试

## 目标

确认 D435i 能被机载电脑识别，USB3 链路稳定，并能通过 ROS 输出深度图。

当前项目已切换为开机自启动避障链路，旧手动检查脚本已删除；本文件保留阶段04-01验收标准和复核命令。

---

## 前置条件

- 阶段03 MAVROS 接入验收通过。
- D435i 已安装并接入机载电脑 USB3 接口。
- 机载电脑已安装 RealSense SDK、ROS Noetic 和 RealSense ROS 驱动。
- `ros_catkin_ws_lite` 已编译完成。

---

## 复核命令

```bash
rs-enumerate-devices
lsusb
rostopic hz /camera/depth/image_rect_raw
rostopic echo -n 1 /camera/depth/image_rect_raw/header
```

如果 OpenCV 运行库混用导致 RealSense 启动失败，可运行：

```bash
cd /home/<user>/X400_workspace/03_SourceCode/ros_catkin_ws_lite
bash src/x400_bringup/scripts/fix_opencv42_runtime.sh
```
