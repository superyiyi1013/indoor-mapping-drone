# 总控参数基线

> 当前基线文件：`02_固件与配置/参数配置/Pixhawk 6C_3.0.params`
>
> 参数导出版本：PX4 1.16.2 / Quadrotor X
>
> 适用对象：X400 室内无 GPS 阶段测试
>
> 更新时间：2026-07-10

---

## 1. 基线使用原则

1. 当前阶段测试统一以 `Pixhawk 6C_3.0.params` 作为主基线。
2. 旧基线文件（0.0 ~ 2.7）只作为历史对照，不作为现场默认基线。
3. 每次修改参数前，先从 QGC 导出当前参数，文件名必须带日期和用途。
4. 参数改动只允许围绕本阶段测试目标进行，不做无关大改。
5. 枚举类参数必须在 QGroundControl 中确认显示名称，不能只看数字。

为什么要这样管理：

- 阶段测试最怕“今天不知道昨天改了什么”。
- 基线统一以后，漂移、拒绝解锁、模式异常、低电量动作异常才有可追溯依据。

## 2. 项目基础配置

| 参数 | 当前值 | 作用 | 阶段测试要求 |
|---|---:|---|---|
| `SYS_AUTOSTART` | `4001` | 机型启动配置，Quadrotor X | 保持 |
| `SYS_HAS_GPS` | `0` | 声明系统无 GPS | 保持 |
| `GPS_1_CONFIG` | `0` | 禁用 GPS1 | 保持 |
| `SYS_HAS_NUM_DIST` | `1` | 声明有 1 个测距传感器 | 保持 |
| `SYS_HAS_NUM_OF` | `1` | 声明有 1 个光流传感器 | 保持 |
| `SYS_HAS_MAG` | `1` | 声明机体有磁力计硬件 | 2.2 保留硬件声明，但 EKF2 不依赖磁罗盘飞室内 |

说明：

- 这是室内无 GPS 方案的基础。飞控必须知道本项目不依赖 GPS，而是依赖 MTF-02 的光流和测距。

## 3. 遥控器与模式基线

| 参数 | 当前值 | 作用 | 阶段测试要求 |
|---|---:|---|---|
| `RC_MAP_ROLL` | `1` | 横滚通道 | QGC 摇杆显示正确 |
| `RC_MAP_PITCH` | `2` | 俯仰通道 | QGC 摇杆显示正确 |
| `RC_MAP_THROTTLE` | `3` | 油门通道 | 油门最低可识别 |
| `RC_MAP_YAW` | `4` | 偏航通道 | 偏航方向正确 |
| `RC_MAP_ARM_SW` | `5` | 解锁开关 | 开关方向明确 |
| `RC_MAP_KILL_SW` | `6` | 急停开关 | 不得误触 |
| `RC_MAP_FLTMODE` | `7` | 模式开关 | 三段档位可识别 |
| `COM_FLTMODE1` | `2` | 模式档位 1（Position） | 必须在 QGC 确认名称 |
| `COM_FLTMODE4` | `1` | 模式档位 4（Altitude） | 必须在 QGC 确认名称 |
| `COM_FLTMODE6` | `8` | 模式档位 6（Offboard） | 必须在 QGC 确认名称 |

现场要求：

- 首飞从 `Stabilized` 开始。
- 确认测距后再测 `Altitude`。
- 确认光流和测距都稳定后，再测 `Hold` 或本地位置有效的定点类模式。
- `COM_FLTMODE*` 不只看数字，要以 QGC 实际显示模式名称为准。

## 4. MTF-02 光流与测距基线

| 参数 | 当前值 | 作用 | 阶段测试要求 |
|---|---:|---|---|
| `MAV_1_CONFIG` | `102` | TELEM2 绑定 MAVLink 实例 1 | 保持 |
| `MAV_1_MODE` | `1` | TELEM2 外设通信模式 | 保持 |
| `SER_TEL2_BAUD` | `115200` | TELEM2 波特率 | 必须与 MTF-02 一致 |
| `EKF2_GPS_CTRL` | `0` | 禁用 GPS 融合 | 保持 |
| `EKF2_OF_CTRL` | `1` | 启用光流融合 | 保持 |
| `EKF2_RNG_CTRL` | `2` | 条件性测距融合 | QGC 确认枚举名称 |
| `EKF2_HGT_REF` | `2` | 高度参考源 | QGC 确认显示 `Range Sensor` |
| `EKF2_MIN_RNG` | `0.02` | 最小有效测距 | 匹配 MTF-02 近距离盲区 |
| `EKF2_OF_QMIN` | `1` | 光流最低质量门限 | 首飞保持，漂移排查时再评估 |
| `EKF2_OF_POS_Z` | `0.00` | 光流 Z 向安装偏移 | 与测距保持一致的默认值（未显式设置） |
| `EKF2_RNG_POS_Z` | `0.00` | 测距 Z 向安装偏移 | 默认值，传感器与 CG 接近同高度 |
| `EKF2_BARO_CTRL` | `1` | 气压计辅助 | 保留兜底能力 |

阶段通过前必须看到：

- `DISTANCE_SENSOR` 有数据，抬高/放低时变化正常。
- `OPTICAL_FLOW_RAD` 有数据，平移飞机时变化正常。

## 5. 数传与外设基线

| 参数 | 当前值 | 作用 | 阶段测试要求 |
|---|---:|---|---|
| `MAV_0_CONFIG` | `101` | TELEM1 绑定 MAVLink 实例 0 | 保持 |
| `SER_TEL1_BAUD` | `115200` | TELEM1 波特率 | 与 LQ 数传一致（最高速率） |
| `MAV_2_CONFIG` | `103` | TELEM3/T3 绑定 MAVLink 实例 2 | 2.2 已为机载电脑/MAVROS 链路预留 |
| `SER_TEL3_BAUD` | `921600` | TELEM3/T3 波特率 | 与机载电脑 `fcu_url` 保持一致 |

说明：

- TELEM1 给 LQ 数传使用。
- TELEM2 给 MTF-02 使用。
- TELEM3/T3 给机载电脑 MAVROS/后续避障链路使用。
- 调参和看传感器消息时优先使用 USB，数传主要用于无线地面站链路验证。

## 7. Collision Prevention 避障基线

| 参数 | 当前值 | 作用 | 阶段测试要求 |
|---|---:|---|---|
| `CP_DIST` | `1.0` | 碰撞预防距离（m），障碍接近此值时日限速/停止 | 保持默认，后续可结合实飞效果评估是否下调 |

## 8. 电池与保护基线

| 参数 | 当前值 | 作用 | 阶段测试要求 |
|---|---:|---|---|
| `BAT1_N_CELLS` | `4` | 主电池串数 | 4S 电池保持 |
| `BAT1_CAPACITY` | `-1` | 电池容量 | 忽略（见下方说明） |
| `BAT1_V_EMPTY` | `3.6` | 单节空电电压 | 保持 |
| `BAT1_V_CHARGED` | `4.2` | 单节满电电压 | 保持 |
| `COM_LOW_BAT_ACT` | `2` | 低电量动作 | QGC 确认枚举名称 |
| `NAV_RCL_ACT` | `1` | 遥控失联动作 | QGC 确认枚举名称 |
| `COM_OF_LOSS_T` | `0.5` | 光流丢失触发时间 | 保持 |

说明：

- `BAT1_CAPACITY=-1` 不填真实容量是有意为之。本项目使用多种型号 4S 电池（容量不统一），现场采用外置 BB 响电压报警器判断电量，不依赖 PX4 电池容量估算。因此该参数保持 `-1`（未设置），低电量保护靠 `BAT1_V_EMPTY` + `COM_LOW_BAT_ACT` 的电压阈值兜底即可。

## 9. 日志基线

| 参数 | 当前值 | 作用 | 阶段测试要求 |
|---|---:|---|---|
| `SDLOG_MODE` | `0` | 从解锁开始记录日志 | 2.2 当前值，便于复盘首飞和异常 |
| `SDLOG_PROFILE` | `1` | 默认日志配置集 | 保持 |

以下情况必须保留日志：

- 首飞
- 改过 EKF2 参数
- 改过光流安装位置
- 出现漂移、定高抖动、拒绝解锁
- 触发低电量或遥控失联保护

## 10. 历史基线说明

旧文件（0.0 ~ 2.7）的主要意义是历史对照。当前总控判断以 `Pixhawk 6C_3.0.params` 为准。

从旧版本到当前基线的关键差异包括：

| 参数 | 旧文档常见值 | 当前基线 | 意义 |
|---|---:|---:|---|
| `EKF2_MIN_RNG` | `0.10` | `0.02` | 当前更贴近 MTF-02 近距离量程 |
| `EKF2_RNG_CTRL` | `1` | `2` | 当前使用条件性测距融合 |
| `EKF2_OF_POS_Z` | `0.10` | `0.00` | 恢复默认值，传感器与 CG 接近同高度不再单独设置 |
| `EKF2_RNG_POS_Z` | 未统一 | `0.00` | 恢复默认值，与光流偏移保持一致 |
| `EKF2_MAG_TYPE` | `0` | `6` | 室内阶段不使用磁罗盘融合航向 |
| `EKF2_MAG_CHECK` | `1` | `0` | 2.2 关闭磁罗盘预飞行检查，避免室内磁干扰阻塞 |
| `MPC_XY_VEL_MAX` | `12` 或更高 | `2.0` | 室内速度明显收紧 |
| `MPC_TILTMAX_AIR` | `45` | `25` | 室内倾角更保守 |
| `MPC_MAN_TILT_MAX` | `35` | `25` | 与 TILTMAX_AIR 保持一致的室内限幅 |
| `MPC_THR_HOVER` | `0.5` | `0.6` | 匹配实际悬停推力估计 |
| `MPC_TKO_RAMP_T` | `0.5` | `1.5` | 阶段06优化后缩短至 1.5s，起飞更果断 |
| `MPC_LAND_SPEED` | `0.7` | `0.6` | 自动降落更保守 |
| `COM_LOW_BAT_ACT` | `0` | `2` | 低电量保护更积极 |
| `BAT1_CAPACITY` | 未关注 | `-1` | 有意保留，使用外置 BB 响报警 |
| `MAV_2_CONFIG` | 未启用 | `103` | 2.2 为 TELEM3/T3 机载电脑链路预留 |
| `CP_DIST` | `-1` | `1.0` | 2.3 首次启用避障（1.0），当前保持默认值 |
| `CP_GO_NO_DATA` | `0` | `1` | 2.9 改为 1，仅前向 D435i 时允许无数据方向移动 |
| `COM_OF_LOSS_T` | `1.0` | `0.5` | 光流丢失触发时间收紧，加速故障响应 |
| `SDLOG_MODE` | `1` | `0` | 恢复默认值，日志记录方式变更 |
