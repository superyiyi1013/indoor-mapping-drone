# 总控回退操作说明

> 适用对象：X400 阶段测试负责人、调参人员、飞手
>
> 当前主基线：`02_固件与配置/配置/Pixhawk 6C_3.0.params`
>
> 关联文件：`07_阶段测试管理/00_总控/03_当前参数基线.md`

---

## 1. 什么情况下必须回退

出现以下任一情况，停止继续测试，先回退到最近稳定参数：

1. 解锁条件突然异常，且无法通过 QGC 提示快速定位。
2. `DISTANCE_SENSOR` 或 `OPTICAL_FLOW_RAD` 原本正常，改参后消失。
3. 切入 `Altitude` 后高度明显跳变或上下窜。
4. 切入定点类模式后横向快速冲出。
5. 电机顺序、电机转向、遥控通道没有问题，但飞行行为突然异常。
6. 低电量、遥控失联、光流丢失保护动作与预期不一致。
7. 不清楚上一轮到底改了哪些参数。

原则：

- 人不确定时，参数必须确定。
- 飞行异常时，先回退参数，再继续讨论原因。

---

## 2. 回退前必须保存现场

回退前不要直接覆盖参数，先保存证据：

1. 用 QGC 导出当前参数。
2. 文件名建议：`回退前_YYYYMMDD_问题描述.params`。
3. 如果已经飞行，保留飞行日志。
4. 在对应阶段文件里记录异常现象。

为什么要保存：

- 不保存现场，就无法判断是哪个参数导致问题。
- 后面复盘漂移、拒绝解锁、模式异常时会失去依据。

---

## 3. 标准回退流程

### 3.1 参数回退

1. 拆桨。
2. USB 连接 QGC。
3. 导出当前异常参数。
4. 导入最近稳定参数文件。
5. 重启飞控。
6. 重新连接 QGC。
7. 对照总控参数基线检查关键项。

当前推荐回退目标：

- 首选：`02_固件与配置/配置/Pixhawk 6C_3.0.params`
- 若后续另存了稳定版本，则回退到最近一次已通过阶段测试的稳定版本。

### 3.2 回退后必须复查的参数

| 参数组 | 必查参数 | 检查目的 |
|---|---|---|
| GPS 与系统 | `SYS_HAS_GPS`、`GPS_1_CONFIG`、`COM_ARM_WO_GPS` | 确认仍是室内无 GPS 配置 |
| 光流测距 | `MAV_1_CONFIG`、`SER_TEL2_BAUD`、`EKF2_OF_CTRL`、`EKF2_RNG_CTRL`、`EKF2_HGT_REF` | 确认 MTF-02 链路和融合没丢 |
| 数传 | `MAV_0_CONFIG`、`SER_TEL1_BAUD` | 确认 TELEM1 数传配置 |
| 机载电脑链路 | `MAV_2_CONFIG`、`SER_TEL3_BAUD` | 确认 2.2 的 TELEM3/T3 MAVROS 预留链路没丢 |
| 磁罗盘策略 | `SYS_HAS_MAG`、`EKF2_MAG_TYPE`、`EKF2_MAG_CHECK` | 确认仍按室内无外置罗盘策略执行 |
| 手感限幅 | `MPC_XY_VEL_MAX`、`MPC_Z_VEL_MAX_UP`、`MPC_TILTMAX_AIR` | 确认室内限速限倾角仍保守 |
| 遥控模式 | `RC_MAP_*`、`COM_FLTMODE*` | 确认遥控和模式开关仍正确 |
| 电池保护 | `BAT1_N_CELLS`、`BAT1_CAPACITY`、`COM_LOW_BAT_ACT` | 确认低电量逻辑可用 |

---

## 4. 回退后测试顺序

回退后不能直接接着飞高难度阶段，必须从低风险环节重新确认：

1. 阶段1：上电与参数检查。
2. 阶段2：MTF-02 静态数据检查。
3. 阶段4：拆桨电机与遥控检查。
4. 阶段5：低空 `Stabilized/Altitude`。
5. 只有前面通过后，才回到阶段6 或阶段7。

原因：

- 参数回退后，系统状态可能恢复了，但硬件、接线、传感器数据仍要重新确认。
- 尤其是光流和测距，不能只相信参数值，必须看 MAVLink 实时消息。

---

## 5. 常见问题回退建议

| 现象 | 优先回退/检查 | 说明 |
|---|---|---|
| 看不到 `DISTANCE_SENSOR` | `SER_TEL2_BAUD`、`MAV_1_CONFIG`、TELEM2 接线 | 先确认数据链路 |
| 看不到 `OPTICAL_FLOW_RAD` | `EKF2_OF_CTRL`、MTF-02 输出协议、地面纹理 | 测距有不代表光流一定有 |
| 定高上下跳 | `EKF2_HGT_REF`、`EKF2_RNG_CTRL`、`EKF2_MIN_RNG` | 先恢复测距高度基线 |
| 定点横向冲出 | `EKF2_OF_CTRL`、`EKF2_OF_QMIN`、`EKF2_OF_POS_Z` | 先回退光流融合相关改动 |
| 手感突然太猛 | `MPC_XY_MAN_EXPO`、`MPC_VEL_MANUAL`、`MPC_XY_VEL_MAX`、`MPC_TILTMAX_AIR` | 先回退手感和限幅参数 |
| 低电量保护不准 | `BAT1_CAPACITY`、`BAT1_N_CELLS`、`COM_LOW_BAT_ACT` | 容量未填会影响判断 |
| 模式开关异常 | `RC_MAP_FLTMODE`、`COM_FLTMODE1/4/6` | 以 QGC 显示名称为准 |

## 6. 回退记录模板

每次回退后，在阶段文件或测试记录中补一条：

```text
日期：
阶段：
异常现象：
回退前参数文件：
回退目标参数文件：
回退后复查结果：
是否恢复正常：
负责人：
```

---

## 7. 禁止事项

1. 禁止在未导出当前参数的情况下直接导入旧参数。
2. 禁止带桨做参数回退后的电机测试。
3. 禁止在未确认 `DISTANCE_SENSOR` 和 `OPTICAL_FLOW_RAD` 的情况下直接测定点。
4. 禁止只凭参数数字判断枚举含义，必须看 QGC 显示名称。
5. 禁止多人同时改参数而不记录。
