# 05_小矩形航线飞行测试

## 目标

执行 1m × 1m 小矩形航线，验证多航点连续执行、角点悬停和闭合回差。路线顺序为：

```
P0（起点）→ P1（前方 1m）→ P2（右侧 1m）→ P3（后方 1m）→ P4（回到起点）
```

采用局部坐标平移方式：以起飞点为原点，按初始机头方向计算四个角点的本地坐标偏移量，依次飞行。每段飞行前原地右转 90°，使前向 D435i 始终面朝运动方向。每段速度 0.15 m/s，航点到达容差 0.15 m，角点悬停 2 s，闭合回差允许 ≤ 0.15 m，高度容差 ±0.1 m。全程保持低速、低高度（默认 1 m），飞手可在任意阶段通过遥控器接管。

---

## 前置条件

- 阶段 07-04 往返直线航点飞行测试已通过。
- 场地尺寸满足矩形路线，路线外侧至少留出 1 m 安全边界。

---

## 建议默认参数

| 参数 | 建议值 | 说明 |
|---|---:|---|
| 高度 | 1 m | 默认飞行高度 |
| 矩形尺寸 | 1 m × 1 m | 小路线低风险验证 |
| 飞行速度 | 0.15 m/s | 低速保证安全 |
| 角点悬停 | 2 s | 观察位置稳定性 |
| 航点容差 | 0.15 m | 到点判定 |
| 闭合回差允许 | ≤ 0.15 m | 与航点容差一致 |

---

## 现场步骤

1. 起飞到目标高度，悬停 5 s，确认坐标稳定。
2. 按 P1 → P2 → P3 → P4 顺序执行矩形航线，每段低速飞行。
3. 每到一个角点悬停 2 s。
4. 完成矩形回到起点后悬停 3 s。
5. 自动降落。
6. 任意阶段出现航点长时间不到达、漂移超过 0.4 m 或异常加速，立即中止路线。

---

## 运行方式

```bash
cd /home/<user>/X400_workspace/03_SourceCode/mavros_auto_flight/stage07
bash 05_rectangle.sh
```

运行后自动完成链路健康检查，弹出安全确认提示，输入 `Y` 后执行全部流程：起飞 → 矩形航线 → 降落 → 打印结果。

可通过环境变量覆盖默认参数：

```bash
RECT_SIZE=0.8 WAYPOINT_SPEED=0.12 bash 05_rectangle.sh
```
