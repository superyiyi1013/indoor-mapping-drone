# 阶段07 — 室内航线自动飞行验收

## 阶段目标

在阶段06 Offboard 起飞、悬停、人工接管和自动降落均通过后，验证 X400 在室内无 GPS 环境下能够基于本地坐标执行低速、短距离航线飞行。

阶段07的重点不是追求厘米级轨迹精度，而是验证：

- 本地位置估计在短时间路线飞行中足够稳定。
- 飞机能按局部坐标航点执行单边、往返、小矩形路线。
- 路线任务中人工接管和异常兜底始终有效。
- 圆形路线先用多航点近似，不做连续高速圆周控制。

本阶段仍然只按“前向 D435i 避障”理解，不能假设侧向和后向具备避障能力。

---

## 当前现场流程

```text
机载电脑上电
  -> systemd 自动启动 bootstrap_sensing_stack.sh
  -> MAVROS + D435i + 前向距离链路常驻运行
  -> 阶段07脚本检查链路健康和本地位置稳定性
  -> 检查通过后执行低速航线飞行动作
```

阶段07脚本后续应继续复用 `mavros_auto_flight` + `flight_core` 架构，不重复启动 MAVROS、D435i 或前向距离节点。

---

## 安全前置检查

修改 `flight_core/safety_config.py` 后，先运行 [06_安全围栏验证测试](06_安全围栏验证测试.md)，确认 `MAX_FORWARD_DISTANCE_M=2.0m`、`MAX_FORWARD_SPEED_MPS=0.5m/s` 围栏生效，再执行下表的路线测试。

## 测试顺序

| # | 文档 | 内容 | 安全要求 |
|---|---|---|---|
| 0 | [00_起飞降落稳定性循环测试](00_起飞降落稳定性循环测试.md) | 起飞→悬停10s→降落，验证起飞和降落程序稳定性 | 每次修改飞行核心后优先运行 |
| 1 | [01_定点悬停与局部坐标稳定性检查](01_定点悬停与局部坐标稳定性检查.md) | 验证光流/下视测距融合后的本地坐标稳定性 | 不通过禁止路线飞行 |
| 2 | [02_Offboard航线模式人工接管测试](02_Offboard航线模式人工接管测试.md) | 路线飞行前先验证接管检测和停止 setpoint | 必须早于自动路线测试 |
| 3 | [03_单边短距离航点飞行测试](03_单边短距离航点飞行测试.md) | 飞到前方短距离航点并悬停 | 前方清空，低速 |
| 4 | [04_往返直线航点飞行测试](04_往返直线航点飞行测试.md) | 前进到航点后返回起点附近 | 验证回差和漂移 |
| 5 | [05_小矩形航线飞行测试](05_小矩形航线飞行测试.md) | 执行 0.8m x 0.5m 小矩形路线 | 每段低速，角点悬停 |
| 6 | [06 矩形航线中途接管复测](矩形航线中途接管复测.md) | 矩形路线执行中切出 OFFBOARD | 验证真实路线中接管 |
| 7 | [07 圆形航线近似飞行测试](圆形航线近似飞行测试.md) | 用 8 点或 12 点近似圆形路线 | 矩形稳定后再做 |

## 建议默认参数

| 项目 | 建议值 | 说明 |
|---|---:|---|
| 默认高度 | `0.8m` | 先低于阶段06 1m 上限，稳定后可升至 1m |
| 单段速度 | `0.12-0.15m/s` | 第一轮不建议超过 0.2m/s |
| 航点到达容差 | `0.15m` | 光流室内定位不按厘米级验收 |
| 起点回差允许值 | `0.25-0.35m` | 小路线闭环后的工程容差 |
| 角点悬停时间 | `1-2s` | 观察姿态和位置稳定性 |
| 最大路线时间 | `60s` | 超时应中止并降落或等待接管 |
| 最大 XY 偏离 | `0.4m` | 超过应中止路线 |

## 阶段07准入规则

- 阶段06 未通过，禁止阶段07。
- 阶段06-01 人工接管未通过，禁止阶段07。
- 阶段06-05 或阶段06-06 的自动降落兜底未通过，禁止阶段07自动路线。
- 本地位置 `/mavros/local_position/pose` 不稳定，禁止路线飞行。
- 自启动避障链路健康检查失败，禁止阶段07飞行脚本起飞。
- 仅有前向 D435i，不允许把侧飞、后退路线当作受避障保护路线。

---

## 路线策略

阶段07第一版路线建议采用“机头朝向下一段，再向前飞”的策略。

原因：当前只有前向 D435i，若使用横向平移或倒飞，D435i 不一定覆盖实际运动方向。矩形路线应优先设计成每条边开始前调整朝向，使前方传感器始终看向前进方向。

圆形路线第一版不做连续圆周控制，而是使用 8 个或 12 个局部航点近似圆形，降低速度连续控制和定位误差累积风险。

---

## 退出条件

全部 7 项测试均通过后，阶段07判定通过。

若只完成 01-05，则可判定“阶段07矩形路线能力通过”；圆形近似作为后半段能力扩展。

任意一项未通过，记录问题，修复后从该项或更早准入项重新执行；涉及接管失败、定位漂移、异常加速、航点长时间不到达时，应回退到 07-01 或阶段06复测。
