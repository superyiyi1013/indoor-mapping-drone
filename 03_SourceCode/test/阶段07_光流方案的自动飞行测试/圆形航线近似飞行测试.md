# 圆形航线近似飞行测试

## 目标

- 在矩形路线稳定后，验证圆形路线的低风险近似飞行能力。
- 第一版不做连续圆周控制，而是使用 8 点或 12 点局部航点近似圆形。
- 观察多航点连续执行时的定位漂移、闭合回差和飞行平顺性。

---

## 前置条件

- [ ] 07-05 小矩形航线飞行测试已通过。
- [ ] 07-06 矩形航线中途接管复测已通过或由安全负责人确认可延后。
- [ ] 场地满足圆形路线，并在圆形外侧至少留出 `1m` 安全边界。
- [ ] 本地位置估计稳定，无明显跳变。
- [ ] 飞手和安全员明确圆形路线范围。

---

## 建议默认参数

| 参数 | 建议值 | 说明 |
|---|---:|---|
| 高度 | `0.8m` | 第一轮圆形高度 |
| 半径 | `0.4m` | 通过后可增至 `0.6m` |
| 航点数量 | `8` | 先用 8 边形近似圆 |
| 飞行速度 | `0.10-0.12m/s` | 比矩形更保守 |
| 航点容差 | `0.18-0.20m` | 圆形近似不宜过严 |
| 每点悬停 | `0.5-1s` | 观察连续性和稳定性 |
| 闭合回差允许值 | `< 0.35m` | 回到起点附近即可 |

---

## 路线建议

第一版用 8 个航点近似圆形：

```text
P0 -> P1 -> P2 -> P3 -> P4 -> P5 -> P6 -> P7 -> P0
```

如果 8 点路线稳定，再考虑：

- 增加到 12 点；
- 缩短每点悬停时间；
- 提升速度到 `0.15m/s`；
- 最后再讨论连续圆周轨迹。

---

## 现场步骤

1. 起飞到 `0.8m`，记录圆心或起点坐标。
2. 悬停 `3-5s`，确认本地坐标稳定。
3. 按 8 点近似圆路线低速飞行。
4. 每个航点到达后短暂停留 `0.5-1s`。
5. 观察每个航点的误差、速度连续性和机体姿态。
6. 完成一圈后回到起点附近，记录闭合回差。
7. 自动降落或人工接管降落。
8. 任意航点长时间不到达、漂移超过 `0.4m`、速度异常或姿态异常，应立即中止。
