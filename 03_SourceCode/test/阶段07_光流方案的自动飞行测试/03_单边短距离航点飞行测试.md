# 03_单边短距离航点飞行测试

## 目标

验证飞机能从起点飞到一个短距离局部航点，验证航点到达判断、到点悬停和自动降落流程，为往返和矩形路线建立最小航点飞行基线。

---

## 本项飞行程序

| 项目 | 内容 |
|---|---|
| 入口脚本 | `03_SourceCode/mavros_auto_flight/stage07/03_single_waypoint.sh` |
| Python 任务 | `03_SourceCode/mavros_auto_flight/tasks/stage07/03_single_waypoint.py` |
| 航点生成 | 按起飞后当前机头方向生成前方局部航点 |
| 到点判断 | 当前 XY 到目标 XY 的误差小于航点容差 |

---

## 前置条件

- 阶段 07-01 定点悬停与局部坐标稳定性检查已通过。
- 阶段 07-02 Offboard 航线模式人工接管测试已通过。
- 前方路径清空，D435i 前向距离链路健康。

---

## 默认参数

| 脚本变量 | 默认值 | 说明 |
|---|---:|---|
| `ALT` | `1.0` | 路线高度，单位 m |
| `PRE_HOVER` | `5` | 起飞后预备悬停时间，单位 s |
| `FORWARD_DISTANCE` | `1.0` | 前方目标航点距离，单位 m |
| `FORWARD_SPEED` | `0.12` | 飞向航点速度，单位 m/s |
| `WAYPOINT_TOLERANCE` | `0.15` | 航点到达容差，单位 m |
| `WAYPOINT_HOVER` | `5` | 到点后悬停时间，单位 s |

---

## 运行方式

```bash
cd /home/<user>/X400_workspace/03_SourceCode/mavros_auto_flight/stage07
bash 03_single_waypoint.sh
```

---

## 现场步骤

1. 确认 07-01 和 07-02 已通过。
2. 确认飞机机头朝向前方安全通道，前方至少 1.5 m 空旷。
3. 运行本项一键脚本。
4. 脚本提示安全确认时输入 `Y`。
5. 脚本自动起飞、预备悬停、按机头方向飞向航点。
6. 到达容差内后脚本打印到达误差并到点悬停。
7. 脚本自动降落。
8. 任意异常立即遥控器切出 OFFBOARD 或 QGC Land。
