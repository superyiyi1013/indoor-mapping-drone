# 06_安全围栏验证测试

## 目标

验证飞行核心的安全围栏是否生效。当前围栏：`MAX_FORWARD_DISTANCE_M=2.0m`、`MAX_FORWARD_SPEED_MPS=0.5m/s`。

测试分三项：
1. `move_forward(3m)` 超限 → 预期抛出 ValueError（围栏拦截）
2. `move_to_local_offset(3m)` 超限 → 预期抛出 ValueError（围栏拦截）
3. `move_forward(0.5m)` 合法 → 预期正常飞行

---

## 前提

安全常量改动后应先运行本测试，确认围栏机制生效，再执行后续飞行任务。

---

## 默认参数

| 变量 | 默认值 | 说明 |
|---|---|---|
| `ALT` | `0.8` | 飞行高度，单位 m |
| `OVER_SIZE_DIST` | `3.0` | 故意超限的距离 |
| `VALID_DIST` | `0.5` | 合法距离 |
| `FENCE_SPEED` | `0.15` | 飞行速度 |

---

## 运行方式

```bash
cd /home/<user>/X400_workspace/03_SourceCode/mavros_auto_flight/stage07
bash 06_fence_check.sh
```

---

## 现场步骤

1. 运行本项一键脚本。
2. 脚本提示安全确认时输入 `Y`。
3. 脚本自动起飞，依次执行三项测试。
4. 观察终端输出：超限项应显示 `✓`（围栏拦截成功），合法项应显示 `✓`（正常飞行）。
5. 脚本自动降落并打印结果汇总。
