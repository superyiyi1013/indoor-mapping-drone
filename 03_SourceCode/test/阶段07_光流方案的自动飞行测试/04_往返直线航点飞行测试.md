# 04_往返直线航点飞行测试

## 目标

验证飞机能从起点飞到前方航点，再返回起点附近。评估短路线中的定位漂移和起点回差，验证路线反向执行时仍能保持低速、低风险。

---

## 本项飞行程序

| 项目 | 内容 |
|---|---|
| 入口脚本 | `03_SourceCode/mavros_auto_flight/stage07/04_out_and_back_waypoint.sh` |
| Python 任务 | `03_SourceCode/mavros_auto_flight/tasks/stage07/04_out_and_back_waypoint.py` |
| 前方航点 | 按起飞后当前机头方向生成前方点 |
| 返回航点 | 返回起飞 home XY 附近，即局部 offset (0, 0) |

---

## 前置条件

- 阶段 07-03 单边短距离航点飞行测试已通过。
- 前后方向均留有安全距离。
- 飞手明确接管方式，安全员到位。

---

## 默认参数

| 脚本变量 | 默认值 | 说明 |
|---|---:|---|
| `ALT` | `1.0` | 路线高度，单位 m |
| `PRE_HOVER` | `5` | 起飞后预备悬停时间，单位 s |
| `FORWARD_DISTANCE` | `1.0` | 前方目标航点距离，单位 m |
| `FORWARD_SPEED` | `0.12` | 往返飞行速度，单位 m/s |
| `WAYPOINT_TOLERANCE` | `0.15` | 前方航点到达容差，单位 m |
| `RETURN_TOLERANCE` | `0.25` | 返回起点回差允许值，单位 m |
| `WAYPOINT_HOVER` | `2` | 航点悬停时间，单位 s |

---

## 运行方式

```bash
cd /home/<user>/X400_workspace/03_SourceCode/mavros_auto_flight/stage07
bash 04_out_and_back_waypoint.sh
```

---

## 现场步骤

1. 确认 07-03 已通过。
2. 确认飞机前后方向均有安全余量，机头朝向前方航点方向。
3. 运行本项一键脚本。
4. 脚本提示安全确认时输入 `Y`。
5. 脚本自动起飞、预备悬停、飞向前方航点。
6. 到达前方航点后悬停，记录到达误差。
7. 脚本返回起点附近（局部 offset 0, 0），记录起点回差。
8. 脚本自动降落。
9. 任意异常立即遥控器切出 OFFBOARD 或 QGC Land。
