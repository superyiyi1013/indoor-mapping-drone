# 00_起飞降落稳定性循环测试

## 目标

- 验证起飞程序能否稳定完成起跳→爬升全流程
- 验证降落程序能否稳定完成下降→触地检测→上锁全流程
- 不评估 XY 漂移，仅判断能否完成完整的起飞→悬停→降落循环
- 每次修改 `flight_core/fly.py` 或 `flight_core/safety_config.py` 中的起飞/降落逻辑后，优先运行本测试

---

## 本项飞行程序

| 项目 | 内容 |
|---|---|
| 入口脚本 | `03_SourceCode/mavros_auto_flight/stage07/00_takeoff_hover_land.sh` |
| Python 任务 | `03_SourceCode/mavros_auto_flight/tasks/stage07/00_takeoff_hover_land.py` |
| 公共飞行层 | `flight_core.fly.Fly.takeoff()` / `Fly.hover()` / `Fly.land()` |
| 通信方式 | 机载电脑 MAVROS |
| 任务结果 | 自动打印起飞/悬停/降落过程日志，无异常即通过 |

---

## 前置条件

- 机载电脑上电后自动避障链路已常驻运行
- `/mavros/state` 中 `connected: True`
- `/mavros/local_position/pose` 有连续稳定数据
- QGC 可见高度、电池、模式
- 安全员到位，遥控器可随时接管

---

## 默认参数

| 脚本变量 | 默认值 | 说明 |
|---|---|---|
| `ALT` | `1.0` | 飞行高度，单位 m |
| `HOVER_TIME` | `10` | 悬停观察时长，单位 s |

---

## 运行方式

```bash
cd /home/<user>/X400_workspace/03_SourceCode/mavros_auto_flight/stage07
bash 00_takeoff_hover_land.sh
```

可通过环境变量覆盖默认参数：

```bash
ALT=0.8 HOVER_TIME=5 bash 00_takeoff_hover_land.sh
```

---

## 现场步骤

1. 上电后确认自启动链路健康
2. 运行本项一键脚本
3. 脚本提示安全确认时输入 `Y`
4. 观察起飞是否果断、无回跌
5. 观察悬停是否稳定
6. 观察降落是否平滑、触地后 disarm 是否成功
7. 任意异常立即遥控器接管
