# 04_拆桨电机与遥控检查

## 目标

确认遥控器、电机顺序、电机转向和急停能力正常。

## 前置条件

- 不装桨。
- QGC 可连接 Pixhawk。

## 测试步骤

| 操作 | 通过标准 |
|---|---|
| 检查遥控通道 | 横滚、俯仰、油门、偏航方向正确 |
| 检查模式开关 | 各档位与 QGC 显示一致 |
| QGC 电机测试 | 电机编号与机体位置一致 |
| 检查电机转向 | 转向符合 X 型四旋翼要求 |
| 测试急停/上锁 | 能立即停止电机输出 |

## 人工观察

- 电机测试时手远离电机。
- 发现电机顺序或方向错误，禁止装桨。

## 通过条件

- 遥控输入正常。
- 电机顺序正确。
- 电机转向正确。
- 急停/上锁有效。

## 结论

状态：✅ 通过  
问题：无  
确认：AI 自动记录 / 2026-06-11
