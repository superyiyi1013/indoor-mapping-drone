# 02_MTF02静态数据检查

## 目标

确认 MTF-02 光流和测距数据能被 Pixhawk 正常接收。

## 前置条件

- `01_上电与参数检查` 通过。
- MTF-02 接在 TELEM2。

## 测试步骤

| 操作 | 通过标准 |
|---|---|
| 查看测距数据 | 可见 `DISTANCE_SENSOR` |
| 上下移动飞机 | 测距值随高度变化 |
| 查看光流数据 | 可见 `OPTICAL_FLOW_RAD` |
| 水平移动飞机 | 光流数据有变化 |

## 命令

```sh
listener distance_sensor
listener optical_flow
listener vehicle_local_position
```

## 通过条件

- 测距数据连续。
- 光流数据连续。
- 数据变化与人工移动方向基本一致。

## 结论

状态：✅ 通过  
问题：无  
确认：AI 自动记录 / 2026-06-11
