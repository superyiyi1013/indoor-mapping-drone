# X400 机载电脑初始化指南

目标：从零部署机载电脑，打通 `Pixhawk ↔ MAVROS ↔ D435i 前向避障`。

固定路径：

```bash
/home/<user>/X400_workspace/03_SourceCode
```

---

## A. 安装依赖

```bash
sudo apt update
sudo apt install -y ros-noetic-ros-base ros-noetic-mavros ros-noetic-mavros-extras
sudo apt install -y python3-catkin-tools
sudo apt install -y ros-noetic-realsense2-camera
```

检查：

```bash
source /opt/ros/noetic/setup.bash && rosversion -d
command -v catkin
rs-enumerate-devices
```

通过标准：
- ROS 显示 `noetic`
- `catkin` 命令存在
- `rs-enumerate-devices` 能看到 D435i
- D435i 接 USB3.0 口

## B. 拉取和编译源码

### B1. 配置 SSH

```bash
ssh-keygen -t ed25519 -N "" -f ~/.ssh/id_ed25519

git clone <your-gitee-repo-url> 03_SourceCode
```

## C. 硬件和串口

### C1. QGC 参数

| 参数 | 值 |
|---|---|
| `MAV_2_CONFIG` | `TELEM3/T3` |
| `SER_TEL3_BAUD` | `921600` |

设置后重新上电 Pixhawk。

### C2. 机载电脑检查

```bash
ls -l /dev/ttyTHS0
groups
```

通过标准：
- `/dev/ttyTHS0` 存在
- `groups` 里有 `dialout`

如没有 `dialout`：

```bash
sudo usermod -aG dialout <user>
```

执行后重新登录。

### C3. 接线

| 机载电脑 | Pixhawk |
|---|---|
| UART1 `/dev/ttyTHS0` TX | TELEM3 RX |
| UART1 `/dev/ttyTHS0` RX | TELEM3 TX |
| GND | GND |

## D. 手动启动验证

先手动跑通，再配置自启动。

### D1. 启动链路

终端 1：

```bash
bash /home/<user>/X400_workspace/03_SourceCode/ros_catkin_ws_lite/src/x400_bringup/scripts/bootstrap_sensing_stack.sh
```

此命令前台运行，不返回。

### D2. 检查 MAVROS 和 D435i

终端 2：

```bash
source /opt/ros/noetic/setup.bash
source /home/<user>/X400_workspace/03_SourceCode/ros_catkin_ws_lite/devel/setup.bash

rostopic echo -n 1 /mavros/state
rostopic echo -n 1 /mavros/local_position/pose
rostopic echo -n 1 /x400/obstacle/front_distance
rostopic echo -n 1 /mavros/distance_sensor/laser_1_sub
rostopic echo -n 1 /mavros/obstacle/send
rostopic hz /mavros/distance_sensor/laser_1_sub
rostopic hz /mavros/obstacle/send
```

通过标准：
- `/mavros/state` 中 `connected: True`
- `/mavros/local_position/pose` 有数据
- `/x400/obstacle/front_distance` 随前方障碍物变化
- `/mavros/distance_sensor/laser_1_sub` 有前向 Range 数据
- `/mavros/obstacle/send` 有持续频率

### D3. QGC 检查

MAVLink Inspector 确认：
- 前向 `DISTANCE_SENSOR` 可见
- 前向距离随障碍物变化
- 前向距离应为 `orientation=0`
- 不要把下视 `orientation=25` 当成前向避障

手动验证通过后，在终端 1 按 `Ctrl-C` 停止。

## E. 配置开机自启动

### E1. 写入 systemd 服务

```bash
sudo tee /etc/systemd/system/px4-perception.service > /dev/null <<'EOF'
[Unit]
Description=PX4 Perception Pipeline (MAVROS + D435i)
After=network-online.target
Wants=network-online.target

[Service]
Type=simple
User=<user>
WorkingDirectory=/home/<user>/X400_workspace/03_SourceCode/ros_catkin_ws_lite
Environment=FCU_URL=/dev/ttyTHS0:921600
Environment=GCS_URL=udp-b://@14550
ExecStart=/home/<user>/X400_workspace/03_SourceCode/ros_catkin_ws_lite/src/x400_bringup/scripts/bootstrap_sensing_stack.sh
Restart=always
RestartSec=3
StartLimitIntervalSec=0

[Install]
WantedBy=multi-user.target
EOF
```

### E2. 启用服务

```bash
sudo systemctl daemon-reload
sudo systemctl enable px4-perception.service
sudo systemctl start px4-perception.service
```

### E3. 验证服务

```bash
systemctl status px4-perception.service --no-pager
journalctl -u px4-perception.service -n 50 --no-pager
tail -n 50 /home/<user>/X400_workspace/03_SourceCode/logs/sensing_stack.log
```

再查话题：

```bash
source /opt/ros/noetic/setup.bash
source /home/<user>/X400_workspace/03_SourceCode/ros_catkin_ws_lite/devel/setup.bash

rostopic echo -n 1 /mavros/state
rostopic echo -n 1 /x400/obstacle/front_distance
rostopic hz /mavros/distance_sensor/laser_1_sub
rostopic hz /mavros/obstacle/send
```

通过标准同阶段 D。

### E4. 重启验证

```bash
sudo reboot
```

重启后重新执行 E3。通过后，自启动配置完成。

重要：`systemctl status` 显示 `active` 只说明服务进程在运行，不等于可以飞。飞行前必须查 MAVROS、D435i 距离、`laser_1_sub`、`obstacle/send` 都有新鲜数据。

## F. 故障排查

| 现象 | 处理 |
|---|---|
| `catkin build` 不存在 | `sudo apt install -y python3-catkin-tools` |
| `rs-enumerate-devices` 看不到 D435i | 查 USB3.0、供电、相机连接 |
| `/dev/ttyTHS0` 不存在 | 查机载电脑 UART 设备名 |
| 用户不在 `dialout` | `sudo usermod -aG dialout <user>` 后重新登录 |
| `/mavros/state` 不是 `connected: True` | 查 Pixhawk 上电、TELEM3、波特率、TX/RX、共地 |
| `/x400/obstacle/front_distance` 无数据 | 查 D435i、RealSense 驱动、USB 连接 |
| `/mavros/distance_sensor/laser_1_sub` 无频率 | 查 D435i 转 MAVROS Range 发布链路 |
| `/mavros/obstacle/send` 无频率 | 查 obstacle LaserScan 发布链路 |
| 服务反复重启 | `journalctl -u px4-perception.service -n 100 --no-pager` |
| 服务 active 但话题无数据 | 查 `sensing_stack.log`，再回到阶段 D 手动启动 |
| 重启后服务没启动 | `systemctl is-enabled px4-perception.service` |
