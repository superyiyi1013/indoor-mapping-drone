# 起飞不够果断 + 降落硬着陆弹跳

## 现象

**起飞**：解锁后电机转速先起来但未离地，离地前有明显减速，随后又增大油门才离地。

**降落**：降到约 40cm 离地时感觉 Offboard 失去管控，飞机加速落地并弹跳，落地偏移变大。

## 根因

### 起飞（两个因素叠加）

1. **`LIFTOFF_DETECTED_ALT_M=0.25m 离地阈值过低`**
   - 光流/下视激光在地面已读 18cm，EKF 高度基线有系统偏移。
   - 当脚本检测到 `rel_alt=0.25m` 时，实际物理离地仅约 7cm，飞机刚进入地面效应区就被判"已离地"。
   - 旧日志中检测点 0.22m 已超旧阈值 0.15m，但爬升段起始目标回缩到 0.15m，命令飞机下降，导致高度从 0.22m 回跌到 0.16m。

2. **`MPC_TKO_RAMP_T=3.0` 起飞斜坡偏慢**（参数侧）
   - 起飞油门 3 秒才到最大，X400 小四轴在此阶段响应迟疑。

### 降落（`MPC_LAND_SPEED` 最小 0.6 决定了不可用 AUTO.LAND）

1. **模式切换速度突变 3 倍**
   - Offboard 下降率 0.20 m/s，在 0.25m 处切 `AUTO.LAND`。
   - PX4 的 `MPC_LAND_SPEED=0.60`（固件下限，无法调低），降速瞬间跳变 3 倍。
   - 飞机在强地面效应区突然以 3 倍速度触地 → 硬着陆 + 弹跳 + 侧滑。

2. **交接高度 0.25m 处于强地面效应区**
   - 模式切换瞬态 + 地面效应 = 飞控瞬间失去高度保持感。

## 改动内容

### `03_SourceCode/flight_core/safety_config.py`

| 参数 | 旧值 | 新值 | 原因 |
|---|---|---|---|
| `LIFTOFF_DETECTED_ALT_M` | 0.25 | **0.40** | 光流地面基线偏 18cm，0.40m 才能确保脱离地面效应区 |
| `TOUCHDOWN_ALT_THRESHOLD_M` | — | **0.05** | 新增。Offboard 全程降落的触地判定阈值 |
| `TOUCHDOWN_CONFIRM_S` | — | **2.0** | 新增。触地确认保持时长，防止弹跳误判 |
| `LAND_HANDOFF_ALT_M` | 0.25 | 保留（弃用） | 新方案不需要 AUTO.LAND 交接 |
| `LAND_HANDOFF_CONFIRM_S` | 0.8 | 保留（弃用） | 同上 |

### `03_SourceCode/flight_core/fly.py` — `land()` 重写

**旧逻辑（已删除）：**
```
Offboard 以 0.20m/s 下降到 0.25m
  → 保持 setpoint 0.8s
  → 发送 NAV_LAND 切到 AUTO.LAND
  → PX4 以 0.60m/s 触地
```

**新逻辑：**
```
Offboard 以 0.20m/s 全程下降到 home_z（地面高度）
  → 持续发送地面 setpoint
  → 检测 rel_alt < 0.05m 持续 2.0s（防弹跳误判）
  → disarm 上锁（无模式切换）
```

### `Pixhawk 6C_3.0.params`（参数侧，已在文件中）

| 参数 | 旧值 | 新值 | 原因 |
|---|---|---|---|
| `MPC_THR_HOVER` | 0.50 | **0.60** | 匹配实际悬停推力（`hover_thrust_estimate ≈ 0.642`） |
| `MPC_TKO_RAMP_T` | 3.0 | **1.5** | 缩短起飞斜坡，起飞更果断 |
| `MPC_LAND_SPEED` | 0.60 | 不修改 | 新降落方案不需要 AUTO.LAND，此参数不再相关 |

## 预期效果

| 阶段 | 旧 | 新 |
|---|---|---|
| 起飞 | 电机启动 → 减速 → 再加油门离地 | 电机启动 → 果断升空，不回跌 |
| 降落 | 0.25m 处加速到 0.60m/s → 硬着陆 + 弹跳 | 全程 0.20m/s → 触地 2s 确认 → 停桨，无弹跳 |
| 落地偏移 | 弹跳中侧滑 | 下降全程 Offboard 位置保持，无模式切换 |
