## 2. 飞控端口分配表

| 飞控端口 | 连接设备 | 用途 | 关键参数 |
|---------|---------|------|---------|
| **POWER1** | Holybro PM06 V2 | 飞控供电 + 电池电压/电流采样 | 6P JST-GH |
| **MAIN OUT 1** | 电调1（右前/CCW） | 电机1 PWM 输出 | 对应 QGC 电机测试 #1 |
| **MAIN OUT 2** | 电调2（左前/CW） | 电机2 PWM 输出 | 对应 QGC 电机测试 #2 |
| **MAIN OUT 3** | 电调3（左后/CCW） | 电机3 PWM 输出 | 对应 QGC 电机测试 #3 |
| **MAIN OUT 4** | 电调4（右后/CW） | 电机4 PWM 输出 | 对应 QGC 电机测试 #4 |
| **TELEM1** | LQ 2.4G 数传天空端 | 地面站无线链路 | 波特率 115200（LQ 最高） |
| **TELEM2** | MTF-02 光流传感器 | 光流数据 + 激光测距 | 波特率 115200，协议 Mavlink_px4 |
| **TELEM3/T3** | 机载电脑串口1 | MAVROS / MAVLink / D435i 避障数据链路 | 波特率 921600，TX/RX 交叉，GND 共地 |
| **RC IN** | 接收机 | 遥控输入 | SBUS/PPM |
| **USB** | 电脑/QGC | 调参、日志下载、固件刷写 | Type-C |
| **GPS1** | 不接 | 室内无 GPS 场景 | 安全开关 Pin6 未使用 |
| **GPS2** | 不接 | 备用 | - |
| **I2C** | 不接 | 备用 | - |
| **CAN** | 不接 | 备用 | - |

## 3. 各子系统详细接线

### 3.1 动力系统

| 部件 | 型号 | 连接关系 |
|-----|------|---------|
| 电池 | 4S LiPo 3000mAh XT60 | → PM06 电源模块输入 |
| 电源模块 | Holybro PM06 V2 | → POWER1（供电+电压/电流采样） |
| 电调 ×4 | 好盈 XRotor 乐天 40A | 信号线 → MAIN OUT 1-4 |
| 电机 ×4 | 郎宇 X2212 KV980 | ← 电调输出 |
| 桨叶 ×4 | 8038（两正两反） | ← 电机 |

**电机布局（X 型，俯视）**：

```
        前
        ▲
   M3(CW)     M1(CCW)
      \         /
       \   ◆   /        ◆ = 飞控位置
        \     /              (箭头朝前)
         \   /
          \ /
           │
          / \
         /   \
   M2(CCW)    M4(CW)
```

> 注：CW = 顺时针转，CCW = 逆时针转。桨叶正反必须与转向匹配。

---

### 3.2 数传系统

**LQ 2.4G 数传模块 ↔ Pixhawk 6C TELEM1**

| TELEM1 引脚 | 信号 | 数传端 |
|------------|------|--------|
| Pin1（红） | 5V | 5V |
| Pin2（黑） | UART7_TX | RX |
| Pin3（黑） | UART7_RX | TX |
| Pin6（黑） | GND | GND |

> Rx/Tx 交叉连接：飞控 TX → 数传 RX，飞控 RX → 数传 TX。

**关键参数**：
- `MAV_0_CONFIG` = TELEM1
- `SER_TEL1_BAUD` = 115200

---

### 3.3 光流系统

**MTF-02 光流传感器 ↔ Pixhawk 6C TELEM2**

| TELEM2 引脚 | 信号 | MTF-02 端 |
|------------|------|----------|
| Pin1（红） | 5V | 5V |
| Pin2（黑） | UART5_TX | RX |
| Pin3（黑） | UART5_RX | TX |
| Pin6（黑） | GND | GND |

> Rx/Tx 交叉连接：飞控 TX → MTF-02 RX，飞控 RX → MTF-02 TX。

**MTF-02 安装要求**：
- 镜头垂直向下
- 模块水平，箭头朝机头方向
- 尽量靠近重心
- 避开桨流和强振动源

**关键参数**：
- `MAV_1_CONFIG` = TELEM2
- `SER_TEL2_BAUD` = 115200
- MTF-02 协议 = Mavlink_px4

---

### 3.4 机载电脑 MAVROS 链路

**Pixhawk 6C T3/TELEM3 ↔ 机载电脑串口1**

| T3/TELEM3 引脚 | 信号 | 机载电脑串口1 |
|------------|------|----------|
| TX | 飞控发送 | RX |
| RX | 飞控接收 | TX |
| GND | 共地 | GND |

> Rx/Tx 必须交叉连接，Pixhawk 与机载电脑必须共地。本机实测机载电脑 UART1 对应 Linux 设备为 `/dev/ttyTHS0`，项目默认 ROS 连接地址为 `/dev/ttyTHS0:921600`；如果后续硬件镜像或接线变化，应以 Linux 实测结果为准。
Pixhawk T3/TELEM3 -> 机载电脑 UART1 -> /dev/ttyTHS0:921600

**关键参数**：
- `MAV_2_CONFIG` = TELEM3/T3
- `SER_TEL3_BAUD` = 921600

---

### 3.5 遥控系统

**接收机 ↔ Pixhawk 6C RC IN**

| RC IN 引脚 | 信号 | 接收机端 |
|-----------|------|---------|
| Pin1 | VCC | 5V（如接收机需要） |
| Pin2 | SBUS | 信号 |
| Pin3 | GND | GND |

> 使用 SBUS 协议。

## 4. 数据流

```
MTF-02 向下观测地面
    ├─ 光流数据 ──→ TELEM2 ──→ PX4 EKF2（水平速度估计）
    └─ 激光测距 ──→ TELEM2 ──→ PX4 EKF2（高度辅助/光流尺度）

遥控器 ──→ RC IN ──→ PX4（飞行模式/油门/姿态指令）

LQ 数传 ←── TELEM1 ←── PX4 MAVLink（遥测/参数/日志）

PX4 控制器
    ├─ 姿态控制 ──→ MAIN OUT 1-4 ──→ 电调 ──→ 电机
    ├─ 高度控制（融合：IMU + 气压计 + 测距）
    └─ 位置控制（融合：IMU + 光流 + 测距）
```

| 端口 | 状态 | 原因 |
|-----|------|------|

| GPS2 | 未接 | 无 GPS 模块 |
| I2C | 未接 | 当前无外接 I2C 传感器 |
| CAN | 未接 | 当前无 CAN 设备 |
| AUX OUT | 未使用 | 四旋翼仅需 4 路主输出 |
| POWER2 | 未使用 | 单电源供电，未做冗余 |
